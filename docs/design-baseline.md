Design v0.1 and Implementation Plan v0.1 (approved 26 November 2026) establish intended behavior and sequencing. The source decision register remains the authoritative approved record in the authorized planning workspace. This page indexes the public-safe derived documents; it is not a second competing specification. Do not publish the original conversation, full planning context or restricted evidence merely because the infrastructure is public.

A1.1 is the initial documentation task. A1.2 upstream audit and A2.1 native Codex compatibility spike are the next ANDES dependency-frontier tasks only after A1.1 is accepted and separately authorized. A1.3 catalog contracts, A1.4 CI/governance, A3.1 task/evidence interfaces and later runtime/research workflows have separate acceptance criteria. Do not close or implement them under A1.1.

The former "Agentic Norms" name and private-first release approach are superseded by decisions 1.4 and 10.1. Public visibility is not stable-release approval. Record discrepancies between accepted design and current implementation instead of silently altering either; change accepted intent only through authorized review. Source and actual receipts control observed behavior; the tracker controls work status. Design v0.1 is not an implementation version.
