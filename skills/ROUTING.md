# ANDES core routing pointers

Select the workflow needed for the current step; do not load all four bodies.

| Current need | Canonical invocation |
|---|---|
| Missing repository/task context, or resume with uncertain evidence freshness | `$andes-orient` |
| Define or resolve acceptance, scope or a consequential interface before implementation | `$andes-contract` |
| Assess a change, failed check or claim of completion against acceptance evidence | `$andes-verify` |
| Leave current artifacts and remaining work ready for another worker | `$andes-handoff` |

Use native discovery metadata to obtain a skill's actual path. Read only the selected skill body and references its current task needs. Move to another workflow only when a distinct next step requires it. A simple request may need none.

A direct invocation selects the named workflow while retaining mandatory project norms, accepted criteria and actual permissions. It does not authorize a new task or bypass a human gate. Unknown or conflicting intent should be resolved with the available project evidence before requesting clarification.
